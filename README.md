**核心判断** : 抖音电商不是"在抖音上卖货"，而是用算法把商品变成内容、把内容变成交易入口的兴趣匹配电商。其底层是"创作—分发—互动"增长飞轮与三层流量池，前端覆盖用户触达、决策、支付、履约、售后全链路，中间衔接商家、达人、服务商与供应链。

**报告摘要 · 核心结论**
-底层逻辑：抖音电商的本质是"内容即渠道"的兴趣匹配电商——用短视频/直播把商品内容化，通过算法实现"货找人"，再以搜索/商城承接"人找货"，构成全域兴趣电商。
-分发机制：流量按场域分为内容场与货架场，成交载体包括直播、短视频、商品卡、图文；免费流量靠"赛马"（完播、互动、转化、GPM），付费流量靠千川（广告流），2024年起付费与自然流量直接联动。
-用户全流程：触达→种草→决策→下单→支付（抖音支付/月付/先用后付）→履约（48小时发货）→售后（运费险、退货券、36小时处理）环环有平台规则兜底。
-中间环节：商家（店播占比近七成）承担技术服务费+达人佣金+广告费；达人通过精选联盟带货，确认收货15天后结算佣金；体验分/口碑分是流量与结算的调节阀。
-边界：货架场景增速放缓（+140%→+49%）、虚假宣传治理压力大、内容与交易的张力、复购率低于传统电商——"货找人"模式有其增长极限。
